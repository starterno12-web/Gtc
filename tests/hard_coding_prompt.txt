السؤال الأخير والأصعب في الاختبار: أنشئ واجهة متصفح فعلية كاملة، وليس وصفاً لها.

اكتب صفحة HTML واحدة قابلة للتشغيل مباشرة، باستخدام HTML وCSS وJavaScript القياسية فقط، دون مكتبات خارجية. يجب أن:
1) تعرض كلمة «شغال» بوضوح.
2) تعرض لوحة ألوان فيها عشرة ألوان مختلفة على الأقل، مع اسم كل لون وقيمة HEX.
3) تتضمن زرّاً يغير خلفية الصفحة إلى اللون المختار، وزرّاً لنسخ قيمة HEX.
4) تعرض رسالة حالة واضحة عند نجاح العملية أو فشلها.
5) تكون متجاوبة مع الهاتف والحاسوب، وتستخدم HTML دلالياً.
6) تربط الأحداث فعلياً باستخدام addEventListener وتحدّث عناصر DOM باستخدام JavaScript.
7) تتعامل مع فشل Clipboard API دون انهيار الصفحة.

أخرج كود HTML/CSS/JavaScript كاملاً وقابلاً للتشغيل، لا تكتفِ بالشرح أو شبه الكود. يجب أن تكون كل الوظائف المذكورة موجودة في التنفيذ.
