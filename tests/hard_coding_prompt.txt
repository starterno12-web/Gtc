اختبار صعب لتوليد الشيفرة — المستوى المتقدم

اكتب ملف HTML واحداً كاملاً يعمل مباشرة في المتصفح، ويحتوي على CSS وJavaScript داخليين فقط، من دون أي مكتبات أو ملفات خارجية.

المطلوب بناء تطبيق عربي RTL لإدارة لوحة ألوان احترافية، مع الالتزام بكل الشروط التالية في حل واحد متكامل:

1. واجهة عربية RTL متجاوبة للهاتف والحاسوب، بخلفية بيضاء وتصميم واضح.
2. اعرض 12 لوناً ابتدائياً على الأقل، وكل لون داخل بطاقة تعرض اسمه وقيمة HEX وقيم RGB.
3. أضف زر توليد لوحة ألوان عشوائية، مع ضمان عدم تكرار اللون نفسه داخل اللوحة.
4. أضف إمكانية إضافة لون يدوياً والتحقق من صحة HEX قبل قبوله.
5. أضف زر نسخ HEX لكل لون، وزر نسخ جميع الألوان دفعة واحدة.
6. أضف بحثاً فورياً يرشح الألوان بالاسم أو قيمة HEX.
7. أضف مفضلة لكل لون، مع حفظ المفضلة واللوحة الحالية في localStorage واستعادتهما بعد تحديث الصفحة.
8. أضف زر تصدير CSS variables بصيغة :root، وزر تنزيل النتيجة كملف palette.css.
9. أضف فاحص تباين بين لون النص والخلفية، واحسب نسبة التباين وفق صيغة WCAG الصحيحة بعد تحويل sRGB إلى linear RGB، ثم اعرض هل النتيجة تحقق AA للنص العادي (4.5:1) وAA للنص الكبير (3:1).
10. أضف اختيار لون النص والخلفية مع معاينة حية، ولا تخلط بين حساب التباين وحساب السطوع التقريبي.
11. اجعل كل الأزرار تعمل فعلياً، وأضف رسائل نجاح وخطأ مفهومة باللغة العربية.
12. استخدم عناصر HTML دلالية، وتسميات واضحة للمدخلات، ودعماً أساسياً للوحة المفاتيح، وحالات focus ظاهرة.
13. تعامل مع فشل localStorage أو clipboard دون انهيار التطبيق.
14. لا تستخدم eval أو innerHTML لإدخال نص المستخدم.
15. لا تضع شروحات أو Markdown أو سياج شيفرة قبل HTML أو بعده. أخرج الشيفرة كاملة فقط.

اختبر منطقك قبل إخراج النتيجة. لا تحذف أي شرط لتقصير الإجابة.
